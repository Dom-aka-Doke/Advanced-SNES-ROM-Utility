Edit ROM Information

Change basic ROM information like title, company, country/region, version, game code and (S)RAM size.

  • Title: Japanese (Shift-JIS) characters are supported. The title is limited by bytes, not by characters (21 bytes for most ROMs). A double byte character is never cut in half.
  • Company: ROMs with the old header store one byte at $FFDA (only companies with a 1 byte code can be chosen). ROMs with the extended header ($FFDA = 0x33) store a 2 character maker code at $FFB0. The codes are converted automatically, f.e. 01 = Nintendo, A4 = Konami.
  • Game Code: only available for ROMs with an extended header; only A-Z and 0-9 are accepted.
  • (S)RAM size: normal ROMs store the size at $FFD8, Super FX games with extended header at $FFBD. Early Super FX games without extended header (f.e. Star Fox / Star Wing) have no field for it - here the size cannot be changed.

The light next to CHECKSUMS shows whether the internal checksum is correct (green) or not (red).

Expand ROM

Expands ROM to a specific size up to 64 Mbit (BS-X up to 32 Mbit). Choose how the new space is filled with Expand fill:

  • Empty (0x00): free space for ROM hacks (default).
  • Empty (0xFF): the same, but filled like an erased (E)EPROM / flash chip.
  • Mirror data: for writing a smaller game to a larger chip (f.e. an 8 Mbit game to a 16 Mbit EPROM). The data is mirrored exactly like the SNES sees it on the original cartridge, also for sizes that are no power of two. Sizes that cannot be mirrored correctly (12, 20, 24, 28 Mbit) are not offered.
  • 48 / 64 Mbit: LoROM and HiROM games are converted to ExLoROM / ExHiROM; the map mode is changed and the parts the SNES reads from the upper area are copied. Games with enhancement chips (SA-1, S-DD1, SPC7110, Super FX) and interleaved ROMs only get free space - data and header stay untouched.

Expanding does not change the header for you: use Fix Internal ROM size and Fix Checksum afterwards. Always check if your ROM still works after doing this!

Deinterleave

Some patches or copy stations require interleaved ROMs. This function will interleave your ROM. If you have interleaved a ROM, patched it and want to play it in an emulator or flashcard, don't forget to deinterleave and fix checksum again!

Note: Only HiROMs can be interleaved!

Remove Overdump

An overdump is a ROM file that is larger than the real chip. The tool recognizes two kinds:

  • Padded data: the file is larger than its internal size and the rest only contains 0x00 or 0xFF.
  • Mirrored data: the end of the file repeats data from before, exactly as the SNES would see it on a smaller chip.

The button is only active if an overdump was found. The tool shows the detected sizes and asks before cutting the file. Afterwards use Fix Internal ROM size, if the tool tells you so.

ROM Heatmap

Shows all ROM banks (32 kByte for LoROM, 64 kByte for HiROM; can be switched):

  • Duplicates: unique banks, banks that are identical to another bank and empty banks (only 0x00 / 0xFF). The bank with the internal header has a dark frame.
  • Entropy: how random the data of each bank is - compressed graphics and music look different from code or empty space.
  • Move the mouse over a bank for details (file offset, SNES address, identical banks). Below the map all groups of identical banks and the overdump result are listed.

Useful to spot overdumps, free space for ROM hacks or bad dumps. The window updates when the ROM changes.

Open, Save and Save As

  • Open ROMs with Select ROM File, File → Open, by dragging a file onto the window or by starting the program with a ROM file (f.e. "Open with").
  • ROMs from 32 kByte (homebrew and test ROMs) up to 16 MByte can be loaded.
  • The open dialog starts in the folder of the last opened ROM. If that folder does not exist anymore, your documents folder is used.
  • When closing the window or opening another ROM with unsaved changes, the tool asks whether to save them.

Options

Expand fill

  • How new space is filled when expanding a ROM: Empty (0x00), Empty (0xFF) or Mirror data. See Expand ROM.

Scan protections on loading

  • Checked: ROM will be scanned instantly for copy protections on loading. This might take a few seconds.
  • Unchecked: You have to manually click the Scan button to check for copy protections.

Commandline (CLI)

Use Windows Commandline (CMD) for executing batch operations (or just for processing a single file, if you prefer using the commandline).

Build your own command chain to execute operations in the order you specified!

Notes:

  • Deinterleaving and interleaving might require user action! This will bring up a windows form and can only work within a Windows environment

  • All paths must be in absolute format

    • Example:

    Advanced_SNES_ROM_Utility -path "C:\ROMs" -recursive -header add -patch "C:\Patches\patch.ips" -header remove -fixromsize -fixchecksum

    This command will add a header to all ROMs in C:\ROMs (subfolders included), apply an IPS patch, remove header afterwards, fix internal ROM size and checksum and save the modfied file with an extension.

    Usage:    
    Advanced_SNES_ROM_Utility [options]
     
    Options:
      -path <FILEPATH, FOLDER> Path or folder of the ROM file(s)
      -recursive Include files from subdirectories
      -overwrite Overwrite files on saving (else an extension will be used)
      -header <add, remove> Adds or removes a header
      -fixchecksum Fixes a broken checksum
      -fixromsize Fixes a wrong internal ROM size
      -removeregion Removes existing region checks
      -removesram Removes existing SRAM checks
      -removeslowrom Removes existing SlowROM checks
      -deinterleave Deinterleave, if ROM is in interleaved format
      -interleave Interleave, if ROM is in deinterleaved format
      -patch <FILEPATH> Patch ROM with a specific patch
      -removeoverdump Removes mirrored or padded data of an overdumped ROM
      -company <CODE> Sets the company by its 2 character code (f.e. 01 = Nintendo, A4 = Konami)
      -sram <0-7> Sets the (S)RAM size: 0 = none, n = 2^n kByte (1 = 2 kByte ... 7 = 128 kByte)
      -log Write output to a logfile
      -version Show version information
      -help Show help and usage information
